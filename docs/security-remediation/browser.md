# Browser security verification

Scope: local clean security worktree, actual Chromium and locally built production image. This report does not establish deployed dev or production closure.

`frontend/e2e/security-sessions-passkeys.spec.ts`: five tests passed using the existing Playwright configuration (`npm.cmd run test:e2e -- security-sessions-passkeys.spec.ts --workers=1`). The refresh/logout test uses two real same-origin tabs and native Web Locks. It checks rotating HttpOnly cookies, single concurrent refresh, no stale-cookie replay, logout queued behind an in-flight rotation, cross-tab epoch invalidation, and cleared in-memory access tokens. Transient refresh failure retains recovery intent and succeeds through the actual Retry UI.

The passkey test uses Chromium's CTAP2 virtual authenticator and actual `navigator.credentials.create/get`; server ceremony endpoints are mocked. It checks challenge/origin/type, authenticator user-presence and user-verification flags, recovery UI, lack of credential/password/token persistence in Web Storage, and that a sensitive failed mutation is not automatically replayed after step-up. Unknown server state and unavailable WebAuthn each disable verification and show recovery guidance. This is browser integration evidence; the identity agent owns real cryptographic verification and PostgreSQL credential/session integration evidence. Authenticator credential storage itself is expected and intentionally retained by the browser authenticator.

The generated-client *test fixture* was updated for mandatory `sessionId` and `stepUpExpiresAt`. The production Docker build passed after this correction. No generated production client or passkey implementation was changed by this work.

`frontend/scripts/verify-container-security.mjs` exercises the built nginx container. It requires CSP, nosniff, frame denial, referrer/permissions policy and HSTS on HTML, built script assets, health response, missing-asset 404 and upstream 502. Chromium checks actual inline-script and PDF-object blocking, allowed raster blob preview and safe blob download. It also opens the actual production order UI against mocked API responses, checks an image preview, and checks PDF download without an inline document. Machine-readable local results are written to `browser-evidence.json` only after every assertion passes. This script requires an actual running container at `FRONTEND_SECURITY_CONTAINER_URL` (default `http://127.0.0.1:18789`).

Initial image startup exposed a concrete nonroot deployment bug: the base image uses `/run/nginx.pid`, whereas the Dockerfile replacement matched only `/var/run/nginx.pid`. The infrastructure owner corrected the pid directive replacement. Rebuilding `ims-frontend-security-local` and running the verification script against the default nonroot container passed all assertions. `browser-evidence.json` records the actual local response headers and Chromium results, including the production OrderAssetField raster preview and PDF download. The temporary proof container was stopped after verification.

Remaining environment verification: deploy the approved corrected image, repeat HTTPS/browser checks against its actual public origin and error paths, confirm gateway/session cookie behavior with real backend storage, and verify passkeys using a real enrolled authenticator and server ceremony. Local HTTP only verifies HSTS header presence, not browser HSTS enforcement over HTTPS.

Final convergence after generated-client/canonical-origin updates: production `npm.cmd run build` passed; all 428 unit tests across 73 files passed with `--maxWorkers=2`; the five targeted security Playwright tests passed again. No frontend source/fixture changes were needed. The initial unbounded unit run hit a 5-second SchoolManagement test timeout during simultaneous production build and Java/PostgreSQL regressions; its unfinished typing contaminated the next test. The unchanged isolated file passed all five tests, and bounded full execution passed. This is an execution-resource issue recorded transparently; no test timeout or gate was weakened.
